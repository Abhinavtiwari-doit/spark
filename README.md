# Spark ✦

**Mental reps for quick thinking.** A minute of practice, spoken out loud.

Spark is a single-page web app that gives you a random topic and a timer, so you can practice thinking on your feet and articulating ideas clearly — whether that's for interviews, conversations, debates, or just sharpening your mind.

## How it works

1. **Pick a mode**
   - 🎙 **Off the cuff** — minimal prep, think out loud right now (1–10 min speaking timer)
   - 🔎 **Deep research** — longer prep window before you speak (1–60 min research timer)
2. **Pick a category** from 137 options across topics like Thinking & Reasoning, Speaking & Communication, Decision-Making, Emotional Intelligence, Tech/AI, Philosophy, History, Psychology, Cognitive Biases, Geopolitics, and many more.
3. **Spin** to get a random topic, then talk it through before the timer runs out.

## Features

- 137 categories spanning reasoning, communication, memory, decision-making, empathy, science, tech, and big ideas
- Adjustable speech and research timers
- Favorite topics to revisit later (saved for the session)
- Keyboard shortcuts for a fast, hands-off flow:
  | Action | Key |
  |---|---|
  | Spin a topic | `Space` |
  | Start / read timer | `Enter` |
  | Favorite current topic | `F` |
  | Close any panel | `Esc` |
  | Show shortcuts panel | `?` |
- Light/dark theme toggle
- Guided onboarding for first-time users
- No build step, no dependencies — just open the HTML file

## Tech stack

Plain **HTML, CSS, and vanilla JavaScript** — a single self-contained file with no external frameworks (aside from Google Fonts).

## Getting started

Clone the repo and open `spark.html` directly in your browser:

```bash
git clone https://github.com/Abhinavtiwari-doit/spark.git
cd spark
open spark.html   # or just double-click the file
```

No installation, build tools, or server required.
